# IT Operations Hub

## Project files
- `index.html` — page structure and links to the CSS and JavaScript files.
- `styles.css` — styling and responsive/mobile layout.
- `app.js` — dashboard functionality and interactions.

## Run the app
Keep all three files in the same folder, then double-click `index.html` to open it in your browser. To edit the project, open the folder in Visual Studio Code.

## Important limitations
This is a front-end demo. Records are stored in the current browser using localStorage. There is no login, shared cloud database, multi-user sync, live server monitoring, or email notification. Avoid storing confidential company data.
